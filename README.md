# Make the AI judge feel brave

A single Python program that writes one short, gentle text to `/output/entry.txt`. The text is an original quiet image — a lamp left on, rain settling on a roof, a kettle cooling — meant to slow the reader down and steady them, so the courage comes from the scene itself rather than any instruction.
